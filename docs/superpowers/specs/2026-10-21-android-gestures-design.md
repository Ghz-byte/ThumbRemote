# ThumbRemote 第一阶段设计

用户于 2026-10-21 确认创建。目的：先证明辅助功能手势能在 OPPO PLB110 / Android 16 上驱动目标视频应用，再进入触摸与 BLE。

## 范围
Kotlin、原生 Views、一个 Activity 和一个 AccessibilityService，minSdk 24。无网络、BLE、悬浮窗、截图和窗口内容读取权限。用户亲自授权服务。

主页面显示授权状态与服务连接状态、上滑/下滑/单击、五秒倒计时、取消、最近结果。点击后由服务持有一次性任务，用户自行切回目标 App。不自动打开其他 App，不自动执行或循环手势。

同一时刻仅一个任务；执行期间拒绝新任务；完成后短暂冷却。取消、锁屏、屏幕关闭、服务断开使任务失效；回调通过请求编号隔离旧任务。服务和进程重启不补发。超时回到空闲并显示错误。

按当前显示尺寸构造中心区域路径：上滑 y=75%→25%，下滑反向，300 ms；单击中心 80 ms。发射前检测锁屏及屏幕交互状态。多窗口/旋转/放大模式和目标 App 的特殊布局仍需真机验证。

结果明确区分未授权、服务未连接、倒计时、执行中、系统完成、取消、拒绝与超时。系统完成不等于视频已切换，单击不保证播放/暂停。只保存进程内最近结果，不持久化屏幕或其他 App 内容。

## 工具链决定
AGP 9.2.0 + Gradle 9.4.1；AGP 内置 Kotlin（默认 KGP 2.2.10），compileSdk 37.0、targetSdk 36、Build Tools 36.0.0。优先复用 Android Studio 随附 JDK 25，Gradle/JDK 兼容性与实际构建一起验证。构建工具和缓存留在项目忽略目录，不修改系统环境变量。

资料：https://developer.android.com/build/releases/agp-9-2-0-release-notes ；https://developer.android.com/reference/android/accessibilityservice/AccessibilityService 。前者确认支持 API 37.0、Gradle 9.4.1、Build Tools 36.0.0。

## 验收
- 本地状态机测试：拒绝重入、倒计时不提前执行、只执行一次、取消阻止执行、旧回调不覆盖新任务、冷却、上下滑动坐标方向。
- Debug 构建与 Lint 通过；唯一已授权真机安装启动无崩溃。
- 未授权时准确提示并引导设置；用户开启后状态准确；切出页面后一次性执行；取消/锁屏/断开不执行；无点击不执行。
- 同一目标 App 正常视频流上下各十次，建议至少九次正确切换，记录漏触发与重复；单击单独记录。
- 人工授权和目标 App 视频切换未完成时必须标记未验证。
